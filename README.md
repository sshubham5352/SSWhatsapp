ChitChat - Real-Time Chat Application
📱 Overview

ChitChat is a modern Android-based real-time messaging application inspired by popular messaging platforms such as WhatsApp. The application enables users to communicate instantly through a secure and responsive chat interface while providing a seamless user experience.

Built using Android development best practices and Firebase Firestore, ChitChat delivers real-time synchronization, push notifications, message status tracking, and user presence monitoring.
